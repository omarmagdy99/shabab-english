# شباب إنجلش — نظام متابعة طلاب دورة اللغة الإنجليزية

تطبيق ويب ثابت (بدون سيرفر) لإدارة ومتابعة طلاب الدورة، مصمم للاستخدام من الهاتف.
البيانات في **Google Sheet** عبر **Google Apps Script**، والموقع يُنشر على **GitHub Pages**.

## الشاشات

| الشاشة | الوظيفة |
| :--- | :--- |
| الطلاب | تسجيل، جدول، تصفية وترتيب واختيار أعمدة، عمليات جماعية، استيراد إكسيل |
| المعلمون | إدارة المعلمين المتابعين، مع مزامنة تلقائية لمن مستواه `معلم` |
| الرسائل | توليد رسالة نصية من نتيجة التصفية الحالية عبر قالب قابل للتعديل |
| السجل | سجل كل العمليات مع التراجع، والأرشيف مع الاسترجاع |

## التشغيل محلياً

```bash
npx http-server . -p 5173 -c-1
```

ثم افتح `http://localhost:5173` واكتب الرقم السري.

## البنية

```
index.html            الهيكل والواجهة (Bootstrap 5.3 RTL)
app.css               نظام التصميم والمكوّنات
apps-script/Code.gs   الباك إند (يُلصق في Google Apps Script)
js/
  config.js           رابط الـ Web App ومفاتيح التخزين
  constants.js        القوائم الثابتة ووصف الحقول
  normalize.js        تطبيع النصوص العربية وأرقام الهواتف
  api.js  store.js    الاتصال بالخادم والحالة المركزية
  query.js            محرك الاستعلام الموحد (بحث + تصفية + ترتيب + أعمدة)
  template.js         محرك قوالب الرسائل
  importer.js         قراءة الإكسيل والتحقق
  ui.js               الدرج السفلي والنوافذ والإشعارات
  app.js              نقطة الدخول والتنقل
  views/              شاشات: students / teachers / messages / history / import
```
